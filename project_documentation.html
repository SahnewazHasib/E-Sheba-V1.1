1. Executive Summary & Project Purpose

E-Sheba is an on-demand, two-sided service marketplace engineered to connect homeowners across Bangladesh with verified blue-collar service providers (plumbers, electricians, appliance technicians, carpenters, cleaners, etc.).

The platform incorporates identity verification using National ID (NID) numbers, recurring monthly subscriptions for providers (৳399/month), location filtering by district and thana, in-app real-time messaging via Pusher WebSockets, masked voice calling via the Agora Web SDK, and payment gateway processing through SSLCommerz (cards, bKash, Nagad, and cash on service). The system is installable as a Progressive Web App (PWA).

C. SSLCommerz Payment Gateway Suite (`sslcommerz/`)

  • sslcommerz/init.php: Initializes transactions for subscriptions (৳399) or customer bookings. Includes an interactive Sandbox Simulator for smooth offline/academic demonstrations.
  • sslcommerz/success.php: Performs server-side validation, activates 30-day worker subscriptions, sets is_visible = 1, and marks bookings as paid.
  • sslcommerz/ipn.php: Server-to-server webhook ensuring subscriptions and bookings activate even if the user closes their browser window prematurely.
  • cron/expire_subscriptions.php: Daily scheduled task hiding expired workers automatically.

D. Real-Time Gmail Verification (`verify-email.php`)

  • 6-digit auto-advancing OTP interface with paste and countdown timer support.
  • Resilient mailer with local session logging fallback so offline presentations never crash.

E. Printable Invoice & Receipt Engine (`invoice.php`)

6. Academic Defense & Viva Q&A Guide

Likely Examiner Question Recommended Technical Answer
"How is phone number masking accomplished?" "We integrated the Agora Web SDK. Both parties join an encrypted dynamic WebRTC audio channel generated on the fly (esheba-call-{minID}-{maxID}). Voice streams peer-to-peer over WebRTC, keeping cellular phone numbers private."
"What happens if the browser closes during an SSLCommerz payment?" "We implemented an Instant Payment Notification (sslcommerz/ipn.php) server-to-server webhook. SSLCommerz calls our IPN listener asynchronously to validate the transaction, updating the database even if the browser session drops."
"How is NID verification securely audited?" "Workers upload a photo of their National ID during registration into uploads/nid/. The Admin Back-Office provides an 'Inspect NID Document' modal where internal staff review the physical ID before toggling is_approved = 1."
"How are SQL Injection and Session Hijacking prevented?" "We enforce PDO prepared statements with ATTR_EMULATE_PREPARES => false across all database queries. For session protection, we call session_regenerate_id(true) on login, enforce CSRF tokens with hash_equals(), and store passwords with Bcrypt via password_hash()."
